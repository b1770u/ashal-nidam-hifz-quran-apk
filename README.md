# أسهل نظام لحفظ القرآن

تطبيق أندرويد لحفظ القرآن الكريم في عامين (24 جدولاً × 30 يوماً)، مع صفحات المصحف بروايتي ورش وحفص، والاستماع، والتسميع الصوتي، والتذكير اليومي، وويدجت الشاشة الرئيسية.

## التحميل

⬇️ **[تحميل آخر إصدار من صفحة الإصدارات](../../releases/latest)**

## التثبيت

1. حمّل ملف `.apk` من صفحة الإصدارات.
2. افتحه على هاتفك، واسمح بـ "تثبيت التطبيقات من مصادر غير معروفة" إذا طُلب منك.
3. يتطلب أندرويد 7.0 أو أحدث، واتصالاً بالإنترنت لتحميل الصفحات والتلاوات.
